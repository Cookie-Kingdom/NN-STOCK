# NN-STOCK (meat-shop)

Meat supply-chain and stock app (Thai UI) for the Owner, the Account Manager and the branches. Next.js 16, Supabase, pnpm.

```bash
pnpm install
pnpm dev         # http://localhost:3000; needs .env.local with the Supabase URL and publishable key
pnpm dev:local   # local SQLite, no Supabase; sign in as <account>@local.test
```

See [CLAUDE.md](CLAUDE.md) and [AGENTS.md](AGENTS.md) for architecture, workflow and commands.
